# HTTP Fundamentals

HTTP (HyperText Transfer Protocol) is the foundation of communication on the web.

Every time you visit a website, open a mobile app, call an API, or load an image, HTTP is usually involved.

This section covers:

- What HTTP is
- Why HTTP exists
- Client-server communication
- Stateless architecture
- HTTP versions
- Request-response lifecycle

## Learning Objectives

After completing this section, you should be able to:

- Explain how browsers communicate with servers
- Understand HTTP requests and responses
- Differentiate HTTP versions
- Understand why HTTP is stateless
- Trace the lifecycle of a web request
